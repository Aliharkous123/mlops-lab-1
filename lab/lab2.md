## Question 2



`--backend-store-uri` specifies where MLflow stores the run metadata. In this lab, the metadata is stored in the SQLite database `mlflow.db`.



`--default-artifact-root` specifies where MLflow stores the artifacts generated by the runs. In this lab, they are stored in the local `mlruns/` folder.



Metadata includes information such as parameters, metrics, run IDs and experiment information, while artifacts are files produced by a run, such as the trained model.

## Question 5

`mlflow.log_param` is used to log values that are fixed for a training run, such as the learning rate, batch size, number of epochs and model.

`mlflow.log_metric` is used to log values produced during training, such as training loss, validation loss and validation accuracy.

Metrics use a `step` because their values can change after every epoch. The step allows MLflow to keep track of the evolution of a metric during training and display it as a graph. Parameters do not need a step because they remain fixed during the run.
